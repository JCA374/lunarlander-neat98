Every run's stages: the world, the reward, the check that ends the stage, the cap and the expected outcome, written down before the stage starts.

What the last two projects taught about curricula

From a clean start a curriculum is needed: a random network first has to learn to fly at all. The order that worked: calm → steady push → gusts 5 → 10 → 15 → turbulence → boulder (shrunk, then full size), with fading training wheels (a torque that pulls the lander upright, fading to zero within the stage) rather than heavy reward shaping.

Easy stages make agents forget: in the NEAT project a 90% agent fell to 52% after calm-air training, because the weights that read the wind sensor drift freely when the wind is zero. So the later stages keep 30–50% real-task flights (rehearsal) and every check also flies the real task.

Hard cases are the curriculum for the last few percent: re-flying recently failed situations in 30% of training flights took PPO from a 92.7% plateau to ~96%. Here they will be training-range seeds the recent champions failed, never check or selection seeds.

A stage pass is "move on", not proof: 200 + 200 check flights get passed by luck after enough tries. The last stage never ends the run; the champion is chosen on ≥ 1,000 selection flights, the top few re-flown on 2,000 more.

The plan for this run (written before it starts)

  1. Calm landing: no wind, no boulder, training wheels 1 → 0.
  2. Wind ramp: steady push → gusts 5 → 10 → 15, then turbulence 0 → 1.5, with rehearsal of calm flights.
  3. Boulder: size 0.4 → 1.0 of full, layout v3, with 30–50% real-task flights.
  4. Real task + hard cases, the long one, no early stop: 30% of flights re-fly failed training seeds; a snapshot every 25 generations.

Pay: 0.3 × game score + 300 per landing − 200 per timeout − 100 per boulder touch, no centre bonus (the game score alone rewards saving fuel, and "points up, landings down" happened before). Each stage's exact settings appear below when it starts.
