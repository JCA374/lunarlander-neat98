The model

The pilot is a small neural network: 16 numbers in (what it sees), 4 numbers out, one per action (nothing, left engine, main engine, right engine). Each step it fires the action with the highest number. Nobody writes its weights: they are evolved with NEAT.

What NEAT is

NeuroEvolution of Augmenting Topologies (Stanley & Miikkulainen, 2002). A population of a few hundred networks (genomes) each fly the same set of flights and get one number back, their fitness. The better ones become parents: their children are copies with small changes (mutations) and mixes of two parents (crossover). Unlike plain evolution of weights, NEAT can also grow the network: add a new connection, or split a connection with a new hidden node. Every new gene gets an innovation number, so two networks with different wiring can still be lined up for crossover. And NEAT protects new ideas with speciation: genomes are grouped by how similar their wiring is, and compete mostly within their species, so a freshly grown structure gets a few generations to tune its weights before it has to beat the polished old ones.

Why NEAT stalled at ~85% two projects ago, and what changes

  • One number per flight. PPO learns from every one of the ~300 steps of a flight; NEAT gets only the fitness. Wind makes that number noisy, so selection was often luck. Now: many flights per genome (32+), the same seeds for every genome in a generation (common random numbers, so differences are the network's, not the weather's), and the top 8–10 re-flown on more flights before one is called champion.
  • Mutations wrecked good networks: children of an 86% parent averaged 70.5%. Now: gentle mutation (most weights nudged a little, replacement ≤ 1%), measured: children must not average more than ~3 points below their parent.
  • A copied pilot is a cage. The old run started from a clone of the hand-written pilot and never left it. Now: a clean start, random genomes.
  • A minimal start is too small. Plain NEAT starts with inputs wired straight to outputs. Here each genome starts with a hidden layer of random tanh nodes, its size taken from a measurement (below).
  • Too slow to afford it. 300 genomes × 32 flights × ~300 steps ≈ 3 M steps per generation. A C++ simulator for training (checked against the Python one) aims for ≥ 10× faster. See Speed.

How big must the network be?

Before evolving, I measure it: the PPO champion (16→128→128→4, 98.6% on two test blocks) is copied by imitation (DAgger) into small networks, 16→8→4, 16→16→4, 16→32→4, 16→16→16→4, and each copy flies 1,000 fresh flights. The smallest that still lands ~98% is the size NEAT must be able to reach. Results appear here when measured. These copies are only a yardstick; none is ever used as a starting genome.
