The model: an evolved network

The pilot is a small neural network: 16 numbers in (what it sees), 4 numbers out, one per action. Each step it fires the action with the highest number. Nobody writes its weights or its wiring: both are evolved with NEAT. On this page you can see the real network, watch it think during a flight, follow how it grew, and see what each kind of mutation does. Everything here is drawn from the run's saved champions.

4 · How evolution changes a network

Every child is a copy of its parent (or a mix of two parents) with a few random changes. In this run, per child:

Nudge a weight

80% of the weights move a little (random, σ = 0.1). Most change is this kind. 1% are replaced by a fresh random value.

Add a connection (5%)

Two nodes that were not linked get a new connection with a small random weight.

Add a node (3%)

An existing connection A→B is split: a new node C goes in between (A→C weight 1, C→B the old weight), and the old link is switched off. At first the network behaves almost the same; later mutations make C useful.

Delete a node (2%) or a connection (2%)

A node and all its links, or one link, disappear. This keeps the network from only ever growing: useless parts can be pruned.

Species: protecting new ideas

A freshly added node usually makes a network a little worse at first, because its weights are not tuned yet. If it had to compete with all the polished networks at once, it would die right away. NEAT therefore sorts genomes into species by how different their wiring and weights are, and a genome competes mostly inside its own species. Each species gets a share of the children in proportion to how good it is; a species that does not improve for 30 generations is removed. The number of species is in the chart above. (I found and fixed a bug here on day 1: after a restart, speciation kept using a stale threshold, and the population fell to 3 species; see the Log.)

5 · Background

What NEAT is

NeuroEvolution of Augmenting Topologies (Stanley & Miikkulainen, 2002). A population of a few hundred networks (genomes) each fly the same set of flights and get one number back, their fitness. The better ones become parents: their children are copies with small changes (mutations) and mixes of two parents (crossover). Unlike plain evolution of weights, NEAT can also grow the network: add a new connection, or split a connection with a new hidden node. Every new gene gets an innovation number, so two networks with different wiring can still be lined up for crossover. And NEAT protects new ideas with speciation (above).

What it is paid for

Each genome's fitness is its average over all its flights of: 0.3 × the game score + 300 for each landing between the flags − 200 for a timeout − 100 for touching the boulder. Landing is what pays. (The game score alone rewards saving fuel, and in an earlier project the score went up while landings went down.)

Why NEAT stalled at ~85% two projects ago, and what changes

  • One number per flight. PPO learns from every one of the ~300 steps of a flight; NEAT gets only the fitness. Wind makes that number noisy, so selection was often luck. Now: 16–32 flights per genome, the same seeds for every genome in a generation (common random numbers, so differences are the network's, not the weather's), and the top 10 re-flown on 40 more flights before one is called champion.
  • Mutations wrecked good networks in the old run (it started from a copied pilot; children of an 86% parent averaged 70.5%). A random start needs the opposite: enough mutation to explore. Now 80% of weights are nudged a little each time, and replacement is rare (1%). Whether this is too strong for a good network is measured later with a mutation-damage test.
  • A copied pilot is a cage. The old run started from a clone of the hand-written pilot and never left it. Now: a clean start, random genomes.
  • A minimal start is too small. Plain NEAT starts with inputs wired straight to outputs. Here each genome starts with a hidden layer of 32 random tanh nodes, a size taken from a measurement (below).
  • Speed. The Python simulator turned out fast enough to start (40,000–50,000 steps per second on 7 workers, 20–90 s per generation). A C++ simulator is planned only if speed becomes the bottleneck. See Speed.

How big must the network be?

Before evolving, I measured it: the PPO champion of the last project (16→128→128→4) was copied by imitation (DAgger) into small networks, and each copy flew 1,000 fresh flights. These copies are only a yardstick; none is ever used as a starting genome.

NetworkLanded, 1,000 fresh flights (v3)
16→8→4 (copy)56.5%
16→16→4 (copy)79.1%
16→32→4 (copy)87.0%
16→128→128→4 (the PPO original)98.9%

Each copy had the same imitation budget (10 rounds × 400 flights), so these are lower bounds on what each size can do, but the trend is clear: 8 or 16 hidden nodes are not enough. So every NEAT genome starts with 32 random hidden nodes (16×32 + 32×4 = 640 connections), and NEAT may add nodes and connections and delete them from there.
